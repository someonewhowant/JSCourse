# Статистика объекта
Language: javascript
Reward: 40

Напишите функцию `getObjectStats(obj)`, которая принимает объект и возвращает новый объект со следующей информацией:
1. `keysCount` — общее количество ключей в объекте.
2. `values` — массив всех значений свойств объекта.

Для решения используйте встроенные методы `Object.keys()` и `Object.values()`.

**Пример:**
`getObjectStats({ name: "Alice", age: 25 })` 
-> `{ keysCount: 2, values: ["Alice", 25] }`
