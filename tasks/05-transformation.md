# Сумма из строк
Language: javascript
Reward: 40

Напишите функцию `sumNumbers(a, b)`, которая принимает два аргумента. Аргументы могут быть как числами, так и строками, представляющими числа.
Функция должна вернуть их сумму как число. 
Если хотя бы один из аргументов невозможно преобразовать в число, функция должна вернуть `NaN`.

**Пример:**
- `sumNumbers(5, "10")` -> `15`
- `sumNumbers("2.5", "2.5")` -> `5`
- `sumNumbers("abc", 5)` -> `NaN`
