# Переменные: let и const
Language: javascript
Reward: 30

В JavaScript важно понимать разницу между `let` и `const`. 
Напишите функцию `createConstants()`, которая:
1. Объявляет переменную `name` с помощью `let` и присваивает ей значение "Alice".
2. На следующей строке меняет значение `name` на "Bob".
3. Объявляет константу `AGE` с помощью `const` и присваивает ей значение 25.
4. Возвращает массив `[name, AGE]`.
