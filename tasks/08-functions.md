# Калькулятор с колбэками
Language: javascript
Reward: 50

Напишите функцию `calculate(a, b, operation)`, которая принимает два числа и функцию `operation` (коллбэк).
Функция должна вызывать `operation` с аргументами `a` и `b` и возвращать результат выполнения.

Также реализуйте две простые функции для проверки:
1. `add(x, y)` — возвращает сумму `x` и `y`.
2. `multiply(x, y)` — возвращает произведение `x` и `y`.

**Пример использования:**
`calculate(5, 3, add)` -> `8`
`calculate(5, 3, multiply)` -> `15`
