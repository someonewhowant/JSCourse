# Создание списка
Language: javascript
Reward: 50

Напишите функцию `createList(items, parentId)`, которая динамически создает список на странице.

Функция должна:
1. Найти родительский элемент по его `id` (используйте параметр `parentId`).
2. Создать новый элемент `<ul>`.
3. Для каждой строки из массива `items` создать элемент `<li>`, установить этой строке текст и добавить `<li>` внутрь `<ul>`.
4. Вставить весь список `<ul>` внутрь найденного родительского элемента.
