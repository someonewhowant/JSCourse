# Переключатель темы
Language: javascript
Reward: 40

Напишите функцию `setupThemeToggle(buttonId, elementId)`, которая настраивает переключение темной темы на странице.

Функция должна:
1. Найти кнопку по её `id` (параметр `buttonId`).
2. Найти целевой элемент (например, `body`) по его `id` (параметр `elementId`).
3. Добавить кнопке обработчик события `'click'`.
4. Внутри обработчика переключать класс `'dark-theme'` у целевого элемента.

**Подсказка:** Используйте метод `classList.toggle()`.
