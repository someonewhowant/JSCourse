# Класс Прямоугольник
Language: javascript
Reward: 60

Создайте класс `Rectangle`, который должен содержать:
1. Конструктор, принимающий два параметра: `width` (ширина) и `height` (высота).
2. Геттер `area`, который возвращает площадь прямоугольника (произведение ширины и высоты).
3. Метод `isSquare()`, который возвращает `true`, если ширина равна высоте, и `false` в противном случае.

**Пример использования:**
```javascript
const rect = new Rectangle(10, 20);
console.log(rect.area); // 200
console.log(rect.isSquare()); // false
```
