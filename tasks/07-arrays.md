# Фильтрация и трансформация массива
Language: javascript
Reward: 60

Напишите функцию `processNumbers(arr)`, которая принимает массив чисел и выполняет следующие действия:
1. Оставляет в массиве только четные числа (используйте метод `filter`).
2. Умножает каждое оставшееся число на 2 (используйте метод `map`).
3. Возвращает итоговый массив.

**Пример:**
`processNumbers([1, 2, 3, 4, 5, 6])` -> `[4, 8, 12]`
