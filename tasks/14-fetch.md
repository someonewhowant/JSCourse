# Получение имен пользователей
Language: javascript
Reward: 60

Напишите асинхронную функцию `getUserNames(url)`, которая загружает список пользователей и возвращает массив их имен.

Функция должна:
1. Выполнить `GET`-запрос по адресу `url`.
2. Проверить, что запрос прошел успешно (свойство `ok`). Если нет — выбросить ошибку с текстом `"Network response was not ok"`.
3. Распаковать данные как JSON (ожидается массив объектов вида `{ id: 1, name: "Ivan", ... }`).
4. Вернуть массив, состоящий только из имен (`name`).
