# Определение типов данных
Language: javascript
Reward: 40

JavaScript имеет 8 типов данных. Иногда оператор `typeof` возвращает неожиданные результаты, например для `null`.
Напишите функцию `getDetailedType(value)`, которая возвращает строку с типом данных.
Для `null` функция должна вернуть `"null"`. Для остальных типов она должна вернуть то же, что и `typeof`.

## Starter Code
```javascript
function getDetailedType(value) {
    // ваш код
}
```
